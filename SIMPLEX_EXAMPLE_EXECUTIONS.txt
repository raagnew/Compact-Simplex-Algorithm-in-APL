     ∇ K←SIMPLEX U;NR;IB;I;J;NA;NS;NC;JB;NT;V;X;L;N;NO;⎕IO                    
[1]    ⍝ THIS FUNCTION SOLVES THE FOLLOWING LINEAR PROGRAM VIA THE            
[2]    ⍝ BASIC SIMPLEX METHOD: DETERMINE ONE OR MORE NONEGATIVE VECTORS X     
[3]    ⍝ WHICH OPTIMIZE THE OBJECTIVE FUNCTION C+.×X SUBJECT TO CONSTRAINTS:  
[4]    ⍝ (((S='≤')⌿A)+.×X)≤(S='≤')/B; (((S='≥')⌿A)+.×X)≥(S='≥')/B; AND        
[5]    ⍝ (((S='=')⌿A)+.×X)=(S='=')/B.  THE ARGUMENT U IS EQUAL TO ONE FOR     
[6]    ⍝ MAXIMIZATION AND MINUS ONE FOR MINIMIZATION.  A, B, AND C ARE        
[7]    ⍝ NUMERIC GLOBAL INPUTS WITH (⍴A) = (⍴B),⍴C.  S IS A CHARACTER GLOBAL  
[8]    ⍝ INPUT VECTOR OF SIGNS '≤≥=' WITH (⍴S) = ⍴B.  OTHER NUMERIC GLOBAL    
[9]    ⍝ INPUT SCALARS ARE BIGM, WHICH IS A POSITIVE NUMBER SIGNIFICANTLY     
[10]   ⍝ LARGER THAN ⌈/|C USED TO FORCE ARTIFICIAL VARIABLES OUT OF THE BASIS,
[11]   ⍝ MAXITER, WHICH LIMITS THE NUMBER OF SIMPLEX ITERATIONS, AND MAXOPT,  
[12]   ⍝ WHICH LIMITS THE NUMBER OF ALTERNATIVE OPTIMAL SOLUTIONS. THE        
[13]   ⍝ EXPLICIT RESULT K IS EQUAL TO: ZERO IF AN OPTIMAL SOLUTION IS        
[14]   ⍝ DETERMINED; ONE IF NO SOLUTION EXISTS; TWO IF THE SOLUTION IS        
[15]   ⍝ UNBOUNDED; AND THREE IF THE ITERATION LIMIT IS ACTIVE.  IF AN        
[16]   ⍝ OPTIMAL SOLUTION IS DETERMINED, THE ROWS OF PRIMAL CONTAIN ONE OR    
[17]   ⍝ MORE DISTINCT ALTERNATIVE PRIMAL SOLUTIONS, THE ROWS OF DUAL CONTAIN 
[18]   ⍝ CORRESPONDING (NOT NECESSARILY DISTINCT) DUAL SOLUTIONS, PRIMAL_OBJ  
[19]   ⍝ CONTAINS THE OPTIMAL VALUE OF THE PRIMAL OBJECTIVE FUNCTION, AND     
[20]   ⍝ DUAL_OBJ CONTAINS THE OPTIMAL VALUE OF THE DUAL OBJECTIVE FUNCTION.  
[21]   ⍝ WITH PERFECT ARITHMETIC, WE SHOULD HAVE PRIMAL_OBJ = DUAL_OBJ.       
[22]   ⍝ ITERATIONS IS THE TOTAL NUMBER OF CYCLES THROUGH THE MAIN LOOP.      
[23]   ⍝ PREVIOUSLY PUBLISHED UNDER ALGORITHMS IN MARCH 1985 APL QUOTE QUAD   
[24]   ⍝ WITH CORRECTIONS IN SEPTEMBER 1985 APL QUOTE QUAD.  THIS VERSION     
[25]   ⍝ ELIMINATES UNDERLINES AND SUPERFLUOUS ROUNDING, AND IT CORRECTS      
[26]   ⍝ SIGNS IN THE DUAL SOLUTION.
